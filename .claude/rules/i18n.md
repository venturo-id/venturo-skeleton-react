# i18n

- Satu namespace per fitur: `src/locales/langs/{id,en}/<feature>.json`; teks bersama (Simpan, Batal,
  Hapus, Baris per halaman) di `common.json`.
- File `id` dan `en` selalu punya key yang sama; key baru ditambahkan ke keduanya di commit yang sama.
- Komponen memakai `useTranslate('<namespace>')`; kode di luar React (hook util, helper) memakai
  `i18n.t()`.
- Pesan validasi Zod dibuat lewat factory `makeSchema(t)` yang dibungkus `useMemo`.
- Bahasa fallback `en` (`fallbackLng` di `locales-config.ts`), pilihan user disimpan di
  `localStorage.i18nextLng`. Detail: `docs/patterns/i18n.md`.
